## Rule
When adding or regenerating `artifacts/repaire-phone-dz/src/components/ui/dropdown-menu.tsx`, ensure it exports ALL of:
`DropdownMenu`, `DropdownMenuTrigger`, `DropdownMenuContent`, `DropdownMenuItem`, `DropdownMenuSeparator`, `DropdownMenuLabel`, `DropdownMenuCheckboxItem`, `DropdownMenuRadioItem`, `DropdownMenuShortcut`, `DropdownMenuGroup`, `DropdownMenuPortal`, `DropdownMenuSub`, `DropdownMenuSubContent`, `DropdownMenuSubTrigger`, `DropdownMenuRadioGroup`

**Why:** The original file was stripped to just 4 exports during initial scaffold. Any code generated by a subagent that uses the standard shadcn set (e.g. `DropdownMenuSeparator`) will throw a runtime SyntaxError unless the full set is exported.
