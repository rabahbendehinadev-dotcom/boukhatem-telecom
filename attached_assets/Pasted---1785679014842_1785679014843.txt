لوحة التحكم الحالية تدخل مباشرة بدون صفحة تسجيل دخول، وهذا غير آمن.

أريد إضافة نظام مصادقة حقيقي وآمن خاص بلوحة الإدارة.

المطلوب:

1. إنشاء صفحة تسجيل دخول احترافية على الرابط:

/admin/login

تحتوي على:

- شعار Repaire Phone DZ
- حقل اسم المستخدم أو البريد الإلكتروني
- حقل كلمة المرور
- زر تسجيل الدخول
- زر إظهار وإخفاء كلمة المرور
- خيار تذكرني
- رسالة واضحة عند وجود خطأ
- تصميم متجاوب واحترافي على الهاتف والكمبيوتر

2. حماية جميع روابط لوحة التحكم:

/admin
/admin/products
/admin/orders
/admin/categories
/admin/clients
/admin/coupons
/admin/banners
/admin/settings

يمنع فتح أي صفحة منها بدون تسجيل الدخول.

عند محاولة الدخول إلى /admin بدون جلسة صالحة، يتم تحويل المستخدم تلقائيًا إلى:

/admin/login

3. لا تستخدم كلمة مرور ثابتة داخل الكود.

يجب تخزين حسابات الإدارة في قاعدة بيانات PostgreSQL داخل جدول منفصل مثل:

admin_users

ويحتوي على:

- id
- full_name
- username
- email
- password_hash
- role
- is_active
- last_login
- created_at
- updated_at

4. يجب تشفير كلمات المرور باستخدام bcrypt أو argon2.

ممنوع نهائيًا تخزين كلمة المرور بشكل واضح داخل قاعدة البيانات.

5. استخدم نظام مصادقة آمن:

- Session داخل HttpOnly Cookie أو JWT داخل HttpOnly Cookie
- Secure Cookie في Production
- SameSite مناسب
- انتهاء صلاحية الجلسة
- تسجيل الخروج الحقيقي
- منع الوصول بعد تسجيل الخروج

لا تخزن Token داخل localStorage.

6. أضف داخل لوحة التحكم صفحة:

Gestion des administrateurs

تسمح للمدير الرئيسي بـ:

- إضافة مستخدم إداري
- تعديل المستخدم
- تغيير كلمة المرور
- تفعيل أو تعطيل الحساب
- حذف الحساب
- تحديد الصلاحية
- مشاهدة آخر تسجيل دخول

7. أريد نظام صلاحيات Roles:

- Super Admin: جميع الصلاحيات
- Admin: إدارة المتجر
- Gestionnaire de stock: المنتجات والمخزون فقط
- Gestionnaire des commandes: الطلبات والعملاء فقط
- Employé: حسب الصلاحيات التي يمنحها له المدير

8. أضف نظام Permissions حقيقي، وليس إخفاء الأزرار فقط.

يجب التحقق من الصلاحيات داخل الـ Backend API أيضًا.

الصلاحيات المطلوبة مثلًا:

- view_dashboard
- manage_products
- manage_categories
- manage_brands
- manage_stock
- manage_orders
- manage_clients
- manage_coupons
- manage_banners
- manage_settings
- manage_admin_users

9. أضف حماية إضافية:

- Rate limiting لمحاولات تسجيل الدخول
- قفل مؤقت بعد محاولات كثيرة خاطئة
- تسجيل آخر دخول
- تسجيل محاولات الدخول الفاشلة
- حماية من CSRF إذا تم استعمال Session Cookies
- التحقق من البيانات داخل الـ Backend
- رسائل خطأ آمنة لا تكشف إن كان اسم المستخدم موجودًا أم لا

10. أضف داخل Sidebar:

- Utilisateurs administrateurs
- Rôles et permissions
- Journal d’activité

11. أريد Journal d’activité يسجل:

- من سجل الدخول
- من أضاف منتجًا
- من عدل منتجًا
- من حذف منتجًا
- من غير حالة طلب
- من غير الإعدادات
- التاريخ والوقت
- عنوان IP عند الإمكان

12. حسّن تصميم لوحة التحكم الحالية:

- ضع شعار Repaire Phone DZ بدل المربع الأبيض في الأعلى
- اجعل الـ Sidebar قابلًا للطي
- أضف Header فيه اسم المستخدم وصورته ودوره
- أضف قائمة Profile وDéconnexion
- أضف Breadcrumbs
- أضف إشعارات المخزون والطلبات
- اجعل الجداول والفلاتر احترافية
- حسّن الواجهة على الهاتف
- في الهاتف يتحول Sidebar إلى Drawer
- جميع الأزرار والنوافذ يجب أن تكون متجاوبة

مهم جدًا:

- لا أريد مجرد واجهة Login شكلية.
- يجب إنشاء Backend Auth حقيقي ومربوط بقاعدة البيانات.
- يجب حماية الـ API والصفحات.
- لا تعرض بيانات الدخول الافتراضية داخل الموقع.
- أنشئ حساب Super Admin أولي بطريقة آمنة باستخدام Seed أو متغيرات البيئة.
- بعد أول تسجيل دخول، يطلب النظام تغيير كلمة المرور الافتراضية.
- لا تعدل أو تحذف الخصائص الحالية في لوحة التحكم.
- طبّق هذه التغييرات فوق النظام الموجود حاليًا.
